# v0.111での利用

## ゲームDLLの準備

.NET 9 SDKを使います。SDKの選択は元の`global.json`の9.0.315と
`rollForward: latestFeature`に従います。Pythonは以下の複製補助スクリプトを使う場合だけ必要です。

自分のSteamインストールにある`data_sts2_*`から管理DLLを`lib/`へ用意します。
元のREADMEのコピー手順、または次の補助スクリプトを使ってください。
実際に参照するDLLの一覧は`Directory.Build.targets`にあります。
v0.111では`Sentry.Godot.dll`も必要です。実物の`GodotSharp.dll`はコピーしません。

```bash
python3 scripts/prepare-game-libs.py /absolute/path/to/data_sts2_macos_arm64
```

補助スクリプトは既存の出力先を上書きしません。ゲーム原本にも書き込みません。
このビルド補助は特定のDLLハッシュを要求しません。動作確認に使った版はMac arm64 v0.111.0です。

## ビルド・テスト・起動

```bash
dotnet build learn-the-spire.sln -c Release
dotnet test learn-the-spire.sln -c Release --no-build
dotnet src/Lts2.AgentHost/bin/Release/net9.0/Lts2.AgentHost.dll
```

`Lts2.AgentHost`は元からあるJSON通信の実行プログラムです。
入力・出力は1行1JSON、ゲームの診断出力は標準エラーへ送ります。
次の入力で初期状態を取得して終了できます。

```json
{"cmd":"reset","seed":"TESTSEED"}
{"cmd":"close"}
```

元のAct生成の既定値を維持しています。キャラクターや難易度の指定も元のAPIに従います。
Ironclad・A0という条件は実ゲームの記録との比較に使った条件であり、
ライブラリや元のAgentHostの入力制限ではありません。

## 保存

`GameHost.ToSaveJson()` / `RestoreFromJson()`を使います。戦闘中の保存は非対応です。
マップへ戻った後の保存には、報酬や休憩を再提示しないため、
`PreFinishedRoom.RoomType=Map`というハーネス専用マーカーを記録します。
この保存はゲーム本体へインポートできません。
ゲーム本体の保存も読み込めますが、任意の局面の完全複製を保証するものではありません。

## 検証範囲と追加機能

通常のテストはゲームDLL上で局面を作ります。実保存や実プレイ記録は不要です。
Act遷移・全ランのテストにはHPの補助があり、自然な初期状態での勝利や戦略の強さの証明にはなりません。

独自の観測形式・操作ログと実ゲーム記録の比較は、
[公開観測アドオン](../addons/public-observation/README.md)として別途ビルドします。
通常のビルド・テストにこのアドオンやそのハッシュ・キャラクター制約は含めません。
実ゲーム比較はMac arm64 v0.111.0、ソロIronclad・A0で行っています。
他キャラ・高難度・Linuxの実ゲームとの同値性や、学習の実行は確認範囲に含めません。
